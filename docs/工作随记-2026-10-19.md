# Transmission 中文适配工作随记

日期：2026-10-19。本文根据实际操作整理，供后续维护使用，是适合公开分享的项目记录。

## 起因与方案

需求来自群晖 Transmission 的中文网页使用问题：相同套件在不同设备上呈现不同语言，希望保留熟悉的中文界面，并给 DS423+ 用户提供可安装、可分享的包。

最初检查了官方网页的本地化路径，随后找到爱好者制作的 Transmission Web Control。用户识别出熟悉的界面，并明确要求以原作者版本为基础继续适配，不更换已有交互习惯。

最终采用 ronggang / 栽培者的归档源码，固定在提交 `054e2edf7ee1ec859cec3ee5661a550481321a27`。网页基线为 1.6.1，下载服务基线为 SynoCommunity Transmission 4.1.3-31。官方网页翻译原型没有纳入发布。

## 检查与发现

1. 下载并拆解原始 x64 SPK，核对 `INFO`、架构、安装脚本、网页目录和核心文件。DS423+ 使用 Geminilake 架构，处于该原始 SPK 的架构列表中。
2. 对原始网页做静态分析，检查作者源码的配置、接口调用和参数保存路径。
3. 对照 Transmission 4.1.3 的 RPC 文档，发现新接口使用 JSON-RPC 2.0、snake_case 字段及新的 RPC 版本协商；原作者界面仍按旧协议组织数据。
4. 新版本仍支持旧协议请求，但需要区分“请求能够回退”和“已经覆盖所有旧版本程序”。本次只对实际 4.1.3 程序进行了运行验证。

## 实现

- 保留作者的表格、分类、目录、统计、标签及设置界面。
- 新增独立 `rpc-compat.js`，在客户端协议边界转换字段名、方法名、最近活动任务标识、分享率字段、缓存单位和文件选择状态。
- 用户输入的路径、URL、标签等作为普通值保留，不参与字段名转换；会话失效时仅重试一次。
- 默认简体中文，补充主题名称、部分设置及安装向导文字。
- 在原有设置保存流程中加入全局及单任务顺序下载，增加默认公开 Tracker 和 IPv4/IPv6 端口检查。
- 把新增设置页放在原有标签页末尾，避免破坏原代码按下标初始化标签页的逻辑。
- 保留官方英文网页入口，方便排查兼容问题。归档项目的旧版本更新提示停用。
- 核心程序及库文件从原始 SPK 原样保留，不进行二进制修改；修改后的 SPK 移除失效的原签名，明确标注非官方未签名包。

## 验证过程

先在独立容器中运行从原 SPK 提取的原始 Transmission 4.1.3，不挂载真实下载目录、配置或任务。

接口测试覆盖：会话字段、统计、可用空间、中文文件名、添加及重复任务、文件选择、顺序下载、限速、标签、开始暂停、最近活动任务、全局设置、校验、删除测试任务、会话重连、用户字符串不被误转换及旧协议请求回退，共 15 项检查通过。

随后实际打开浏览器，在中文设置页修改并保存全局顺序下载及默认公开 Tracker，后台读回值一致。清除测试值，并在隔离文件系统中运行网页替换及回退脚本。

成品 SPK 中的 16 个核心可执行文件和库文件与原始文件 SHA256 一致。打包时还核对包内路径、重复成员、网页入口、架构列表、校验值及签名状态。

## 实际 DSM 升级

在用户授权后，先通过 DSM 停止测试 NAS 上的 Transmission，备份程序、套件元数据、配置及任务/恢复记录，校验备份压缩包和原版 SPK。下载文件本身不搬动、不删除。

通过 DSM 套件管理命令执行真实 SPK 升级，并重新启动服务。DSM 返回升级成功、运行状态正常；原有任务被正常加载，任务文件逐一校验一致，恢复记录保留，账号设置及配置与备份一致。安装后核心文件再次校验通过，原 HTTP 登录认证保持有效。

日志中仍有部分 Tracker 连通/通告错误。对照升级前日志，原先也存在同类错误，因此没有把它们误判为中文界面导致，也没有擅自修改 Tracker。

实际升级平台为 SA6400 / DSM 7.4.1。DS423+ 的全新安装和长期下载/做种没有在本次完成，不能把架构匹配等同于该机型真机验证。

## 发布准备与维护经验

- 将来源锁定、适配代码、网页增量修改和套件重打包拆开，后续升级可以逐层检查。
- 原有构建脚本含本机路径，公开前改成相对路径和独立工作目录。
- 显式固定换行符，重新构建的 SPK 与实际 DSM 升级使用的 SPK SHA256 完全一致。
- 公开集成测试增加显式开启开关、仅允许 localhost 测试端点、测试目录及初始空任务检查，减少误用日常下载服务的风险。
- 保留作者署名、第三方许可证、来源提交与校验值，随发行版提供下载内核和套件构建工程源码归档。
- 自定义套件修订号 3101 高于官方 31，后续维护须核对 DSM 版本比较，不能假定官方 32 能直接覆盖。
- 官方套件升级可能覆盖中文网页，应保留网页包，在新版本验证后重新应用相应版本。
