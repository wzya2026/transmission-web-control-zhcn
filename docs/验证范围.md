# 验证范围

## 已执行

- 在隔离容器中运行从原 SynoCommunity SPK 提取的 Transmission 4.1.3。15 项接口测试通过，原始结果见 `rpc-test-results.json`。
- 实际浏览器打开中文网页，修改全局顺序下载及默认公开 Tracker 并保存，服务端读回值一致；测试值随后清除。
- 网页安装与恢复脚本在隔离的模拟 NAS 文件路径中执行通过。
- 在 SA6400 / DSM 7.4.1 上，先停止服务并备份程序、配置、套件元数据及任务记录，再通过 DSM 的 `synopkg install` 从原版 4.1.3-31 升级为 4.1.3-3101；升级各阶段及启动成功。
- 升级后套件状态为 running，已有任务正常加载，任务文件逐一校验一致，恢复记录保留；配置及账号字段均与备份一致。
- 16 个原始核心可执行文件和库文件在成品和安装后均通过 SHA256 比对，未被修改。
- 实际网页端口仍要求原来的 HTTP 登录认证，未放宽访问控制。

以上现场核对没有把 NAS 的备份、配置、凭据或实际任务列表放入仓库。
