# Transmission 中文适配版

本包以“栽培者 / ronggang”的 **Transmission Web Control 1.6.1** 为基础，保留经典中文表格界面，针对 SynoCommunity **Transmission 4.1.3-31** 更新。网页版本为 **1.6.1-zhCN.1**，自定义套件版本为 **4.1.3-3101**。

适用对象：**DS423+（Geminilake）**、SA6400（Epyc7002）及安装包 INFO 中列出的 x64 机型；DSM 最低版本为 7.1-42661。不适用于 DS423（没有“+”的 ARM 机型）。

这是非官方社区适配包，不是原作者或 SynoCommunity 发布的新版本。原作者署名、许可证和原版下载程序均保留。

## 选择安装方式

### 朋友的 NAS 尚未安装 Transmission

1. 解压分享包，找到 `Transmission-4.1.3-3101-zhCN-x64-DSM7.spk`。
2. 在群晖打开“套件中心 → 手动安装”，选择这个 SPK。
3. 根据中文向导填写下载共享文件夹名称，例如 `downloads`。这里填写的是共享文件夹名称，不是 `/volume1/...` 完整路径。
4. 自行设置网页用户名和密码。**这套登录信息属于 Transmission，不是群晖管理员的登录信息。**不要使用原版留空时的默认 admin 密码。
5. 安装后打开 `http://群晖IP:9091/transmission/web/`，输入上一步设置的账号密码。
6. 若提示下载目录无权写入，进入“控制面板 → 共享文件夹 → 编辑 → 权限”，切换到“系统内部用户”，为 `sc-transmission` 勾选该下载文件夹的读写权限。

**实际 DSM 安装状态：已在 SA6400、DSM 7.4.1 上通过 DSM 套件管理命令完成从原版 4.1.3-31 的升级，套件启动正常，原有配置和任务记录保留。**尚未在 DS423+ 验证全新安装。本 SPK 没有 SynoCommunity 官方签名，DSM 可能提示未知发布者或拒绝安装。若 DSM 报签名错误，请保留报错，不要关闭系统校验；可先安装官方原包，再采用下述网页替换方式。

### NAS 已经装好官方 Transmission，里面已有下载任务

建议使用附带的“网页替换包”，避免为了界面变化重装整个套件。

1. 将 `transmission-web-control-zhCN.tar.gz`、`web-ui.sha256`、`install-web-ui.sh` 和 `restore-web-ui.sh` 放在 NAS 的同一个目录。
2. 管理员通过 SSH 进入这个目录，运行：

   ```sh
   sudo sh install-web-ui.sh
   ```

3. 脚本校验文件后，会先备份原网页，再替换网页目录。下载服务、现有任务和账号设置不在脚本修改范围内。屏幕上会显示原网页的备份路径。
4. 回到浏览器，按 `Ctrl+F5` 强制刷新。
5. 需要恢复时，在同一目录运行：

   ```sh
   sudo sh restore-web-ui.sh
   ```

脚本只接受标准 `/volume数字/@appstore/transmission` 套件路径；没有找到标准路径时会停止。不要卸载已有套件来解决网页显示问题。

## 新增与更新

- 默认简体中文，主题名称和安装/升级/卸载向导中文化。
- 4.1 新接口适配：JSON-RPC 2.0、snake_case 字段、最近活动任务、分享率字段、缓存单位和文件选择状态。
- 保留旧服务的旧协议回退路径；旧版本没有进行独立程序实测。
- “基本设置”增加新任务默认顺序下载；单个任务的“设置”中也可调整顺序下载。
- “新版功能”中增加默认公开 Tracker 和 IPv4/IPv6 端口检查。
- 默认公开 Tracker **只用于公开种子**，私有种子不会应用这项默认设置；不同组之间空一行，组内备用地址相邻填写。
- 原界面的分类、目录、统计、标签和设置操作保留。“官方原版”可切回官方英文网页，便于排错。
- 停用已归档项目的旧更新提示，避免误提示覆盖本适配版。

## 已验证与边界

已在独立测试容器运行从原始 SPK 提取的 Transmission 4.1.3，未挂载任何真实下载目录或用户配置：

- 15 项接口测试通过：添加/重复任务、中文文件名、开始/暂停、校验、文件选择、限速、标签、顺序下载、全局设置、统计、可用空间、会话重连及旧协议请求回退等。
- 浏览器实际打开中文界面，在“参数”窗口修改顺序下载和默认 Tracker 并保存，服务端读回值一致。
- 原始 SPK 内 16 个可执行文件和库文件在成品中 SHA256 一致。
- 网页替换和回退脚本已在独立模拟 NAS 路径中执行通过。
- 已在 SA6400 的 DSM 7.4.1 上实际升级，服务启动、已有任务加载、配置和核心程序校验通过；原账号密码保持不变。
- 没有执行新建 BT/PT 下载或长期做种测试；没有在 DS423+ 真机安装本 SPK，尚未验证该型号的全新安装流程。

IPv6 端口检查依赖 NAS 的 IPv6 网络及上游检查服务；检查失败不一定意味着下载功能故障。
